# Emlak Stüdyom - Resmi Kurumsal Logo & Marka Paketi

Bu klasör, Emlak Stüdyom uygulamasının güncellenmiş ve onaylanmış resmi marka kimliği dosyalarını içerir.

## Slogan / Alt Metin
**"EMLAKÇILAR İÇİN FOTOĞRAF DÜZENLEME PLATFORMU"**

## Dosya Kataloğu

1. **`Emlak_Studyom_Master_Logo.svg`**
   - **Kullanım:** Web, Canva, Illustrator, CorelDraw, Figma, baskı ve tabela.
   - **Özellik:** Vektörel format, sıfır pikselleşme, sonsuz ölçeklenebilir çözünürlük.

2. **`emlak_studyom_light_master.png`**
   - **Kullanım:** Açık / beyaz zeminli dokümanlar, antetli kağıt, faturalar, PDF raporlar.
   - **Çözünürlük:** 2400 x 1600 Ultra-HD.

3. **`emlak_studyom_dark_master.png`**
   - **Kullanım:** Koyu tema arayüzler (Slate 900), sosyal medya kapakları, video kapanış jenerikleri.
   - **Çözünürlük:** 2400 x 1600 Ultra-HD (Luminous Cyan / Beyaz).

4. **`emlak_studyom_navbar_master.png`**
   - **Kullanım:** Web sitesi üst menü çubuğu (Header) ve yatay antetler.
   - **Çözünürlük:** 1700 x 360 Yatay Yerleşim.

5. **`emlak_studyom_app_icon_master.png`**
   - **Kullanım:** Masaüstü uygulama simgesi, mobil PWA rozeti, Favicon ve mağaza ikonu.
   - **Çözünürlük:** 1024 x 1024 Yuvarlatılmış Squircle Rozet.

6. **`emlak_studyom_transparent_master.png`**
   - **Kullanım:** Şeffaf zeminli tam logo (filigran ve görsel üstü bindirmeler).

7. **`emlak_studyom_icon_only.png`**
   - **Kullanım:** Yazısız tekil çatı + ES + piksel amblemi (şeffaf zemin).

8. **`emlak_studyom_desk_mockup_final.jpg`**
   - **Kullanım:** Tanıtım sunumları, yatırımcı sunumları ve pazarlama görselleri.
